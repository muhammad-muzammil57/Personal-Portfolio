# Muzammil Pervaiz | Personal Portfolio & Web Developer Showcase

## Overview
This project is a **personal portfolio website** for Muzammil Pervaiz, a professional website developer. The site is designed to showcase his skills, projects, services, and provide an easy way for clients or potential employers to get in touch. It emphasizes clean UI, smooth interactions, and responsive design to ensure an optimal user experience across all devices.

---

## Author
**Muzammil Pervaiz**  
- Role: Full-Stack Web Developer  
- Specialization: Web Development, App Development, Website Hosting  

---

## Purpose
The primary goal of this project is to:

- Present a professional online presence for Muzammil Pervaiz.
- Showcase completed projects with detailed descriptions and live demo links.
- Highlight skills and technologies mastered by the developer.
- Provide easy communication channels for prospective clients through contact forms and call-to-action buttons.
- Demonstrate modern web development best practices including responsive design, clean UI, and engaging animations.

---

## Features

### Hero Section
- Introduces the developer with name and role.
- Call-to-action buttons for hiring and contacting.
- Animated hero image with decorative shapes.
- Tech stack chips to highlight skills.

### Services Section
- Professional services offered:
  - Website Development
  - Mobile App Development
  - Website Hosting
- Each service includes an icon, title, and description.

### About Section
- Personal introduction and background.
- Statistics highlighting achievements:
  - Completed Projects
  - Client Satisfaction Rate
  - Years of Experience
- Highlights developer practices such as clean code, pixel-perfect UI, and performance optimization.

### Projects Section
- Displays live projects with thumbnails, descriptions, and technology stack.
- Example projects:
  1. **Gemini-AI Clone** – A modern AI clone project built with React, Node.js, PostgreSQL, and JavaScript.
  2. **Weather App** – A smart weather application using HTML5, Next.js, and JavaScript.
  3. **Rental-Car Service** – A seamless car rental platform built with HTML5, Node.js, and JavaScript.

### Contact Section
- Easy contact options with call-to-action buttons for booking calls and sending messages.

### Footer
- Contains copyright.
- Navigation links for Resume, About, and Contact.

---

## Technologies Used
- **Frontend:**
  - HTML5
  - CSS3
  - JavaScript (ES6+)
  - Next.js (for certain projects)
  - ScrollReveal.js (for smooth animations)
  - Remix Icons (for icons)
  - Google Fonts (Poppins)
- **Backend / Full-Stack:**
  - Node.js
  - PostgreSQL (for Gemini-AI Clone)
- **Version Control:**
  - Git & GitHub
- **Deployment:**
  - Vercel (for live projects)
